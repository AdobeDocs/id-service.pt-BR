# Perguntas frequentes de outras soluções da CX Enterprise{#faqs-for-other-experience-cloud-solutions}

Perguntas frequentes sobre recursos, funcionalidades e problemas relacionados ao uso de outras soluções CX Enterprise com o Serviço de ID de visitante.

## Analytics e Audience Manager {#section-b3dd206d497041acb04554c6fb1c912a}

**O histórico de visitas de um usuário poderá ser exportado do Adobe Analytics para o Audience Manager depois que eu implementar o Serviço de ID de visitante?**

Existem duas opções aqui:

* Se um usuário tiver uma atividade de visitação após a implementação do Serviço de ID de visitante, o visitante e seu histórico serão incluídos na exportação de dados para o Audience Manager.
* Se um usuário não tiver uma atividade de visitação após a implementação do Serviço de ID de visitante, o visitante e seu histórico não serão incluídos na exportação de dados para o Audience Manager. Como a nova atividade não está presente, não temos como associar a ID do Analytics à ECID.
